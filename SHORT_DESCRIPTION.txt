SymPy Repair Lab evaluates whether coding agents can fix real library bugs while preserving behavior elsewhere. Seven tasks use pinned SymPy checkouts, actual agent tools, deterministic external grading, and three fresh sessions per model. The central repeatable failure fixes foreign-object equality but silently drops an edge in a geometry consumer; an executable demo shows the recorded failure and correct behavior. Raw outputs, controls, grading corrections, and replay instructions are included.
